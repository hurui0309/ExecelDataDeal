#### 记录 id=277：农村经济效益(一).xlsx — p1 子表

- **策略**: strategy_multi_header
- **DB 表名**: ods_rural_economic_efficiency_1_2_1978_2021_p1
- **行数**: 29 行（原始 74 行，实际 29 行，保留 39%）
- **置信度**: 0.45
- **审查结论**: 部分符合
- **问题详情**:
  1. **列名翻译失败**：DB 列名为 `item, col_1, col_2, col_3, col_4, col_5, col_6, col_7`，其中 col_1~col_7 未正确翻译。对照原始 Excel，列名应为：unit(单位), y_1978(1978年), y_1980(1980年), y_1981(1981年), y_1982(1982年), y_1983(1983年), y_1984(1984年)。
  2. **数据内容对照**：首行 "1．农村社会总产值, 元／人, 654.6, 869.6, null, null, 1180.1, 1398.6" 与 Excel 源文件 Row 7 完全一致，数据内容正确但列名有误。
  3. **行数差异**：原始 74 行包含两个子表，p1 仅入库第一个子表约 29 行数据，属于正常拆分行为。

- **根因分析**：
  Classifier 给出 header_start=3, header_end=5, data_start=6。在数据数组中：
  - data[3] = "一、平均每一农村劳动"（分类标题行，仅首列有值）
  - data[4] = "力生产量"（分类标题行续行，仅首列有值）
  - data[5] = "1．农村社会总产值, 元／人, 654.6..."（数据行）

  策略处理流程：
  1. 底部分类标题行裁剪：data[5] 不是分类标题行（有多列值），停止裁剪
  2. _merge_multi_row_header：data[3-4]被跳过，data[5]的数值被当作列名
  3. P4数字列检测：检测到列名含数字，header_end 减为4
  4. 重新合并：header 范围(3-4)全是分类标题行 → 列名退化为 col_1~col_7

  **真正的 header 行是 data[2]（Row 4：'单位, 1978年, 1980年...'），但 Classifier 的 header_start=3 跳过了它。**

2. **高null率列（低优先级，无需修复）**：原始数据缺失导致，非解析错误。

3. **多行合并null率（低优先级，无需修复）**：多行合并项目的后续行本身无数据，属正常现象。
